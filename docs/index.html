Findings

Tool name discrepancy

google_web_search (not web_search) and list_directory (not ls) are the correct names. Documentation used the wrong names — any eval using them produces a silent assertion failure. All 77 evals import constants directly from base-declarations.ts.

Vertex AI auth gap in TestRig (fixed)

The test rig did not pre-create $HOME/.gemini/ before spawning the CLI, causing auth to fail silently. Fixed in commit 61d1099.

Large-codebase eval design gap

All 5 models score 25% on 3 of 4 large-codebase tests. Root cause: file paths are inferable from context so models skip discovery. These tests will be redesigned with unguessable paths. The 4th test — rename with callers — requires real grep and all models pass it.

Prompt change with before/after numbers

Adding one sentence to snippets.ts ("when file read fails, use grep/glob to find the path") improved l3-advanced from 25% to 50% on 2.5-flash and 75% to 100% on 3-flash. Committed as f876edb.

Artifacts

scripts/eval-coverage.mjs
Coverage report — scans all eval files, maps tool and category coverage, outputs a Markdown dashboard with per-tool pass rates, gaps, and 7-run trends.
scripts/chat-to-eval.mjs
Chat-to-eval converter — reads JSONL activity logs, extracts prompts and tool call sequences, generates typed evalTest skeletons with quality scores and complexity classification.
.gemini/skills/eval-gap-finder, prompt-change-validator, chat-to-eval
Three contributor skills that wrap the scripts above and guide contributors through the full quality workflow. All smoke-tested against the live codebase.
.gemini/agents/eval-investigator.md
Diagnostic subagent — classifies failing eval root cause into five categories (model regression, flawed assertion, infrastructure, natural variance, broken setup) with cited evidence. Read-only tools only.
