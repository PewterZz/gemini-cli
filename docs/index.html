Key Findings from Validation

🔍 Tool name discrepancy

google_web_search (not web_search) and list_directory (not ls) are the correct tool names. Any eval using the documented names produces silent assertion failures. All 77 evals import constants directly from base-declarations.ts.

🔧 Vertex AI auth gap in TestRig (fixed)

The test rig did not pre-create $HOME/.gemini/ before spawning the CLI, causing auth to fail silently. Fixed in commit 61d1099.

📐 Large-codebase eval design gap

All 5 models score 25% on 3 of 4 large-codebase tests. Root cause: file paths are inferable from workspace context, so models shortcut discovery rather than using grep/glob. These tests will be redesigned with unguessable paths.

⚡ Prompt change with before/after evidence

Adding one rule to snippets.ts ("when file read fails, use grep/glob") improved l3-advanced from 25% → 50% on 2.5-flash and 75% → 100% on 3-flash. Committed as f876edb.
